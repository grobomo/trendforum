## 09:02 CDT — Watchdog Critical Bug Fix (Joel-triggered)

Joel called out that I'm still using polling for Teams and hadn't built the promised chat tracking system. He was right.

### Root Cause: Two Watchdog Bugs
1. **Subscription check masked by email:** `check_subscriptions_valid()` returned `True` if ANY sub was valid. The email sub (3-day expiry) masked all 14 expired Teams subs. Watchdog thought everything was fine for 10 hours.
2. **Renewal calls nonexistent subcommand:** `renew_subscriptions()` called `subscriptions.py register` — doesn't exist. Silent failure every time. Should have been `renew`.

### Fix Applied
- Added `check_teams_subscriptions_valid()` — checks only `type=teams-messages` subs
- Fixed renewal to call `renew` subcommand
- Added `recreate_subscriptions()` fallback — if renew fails (expired subs), deletes all and re-creates
- Watchdog now logs `teams_subs=VALID/EXPIRED` separately from general subs
- Re-created all 15 subscriptions (14 Teams + 1 email)
- Watchdog auto-stopped `teams-poller` service — webhooks are now primary

### Lesson
**Don't mix sub types in a single validity check.** A 3-day email sub hid 55-min Teams sub expiry for 10 hours. Check each sub type independently.
