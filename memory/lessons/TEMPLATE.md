# Lesson Template

Use this format for all lesson files in `memory/lessons/`.

```markdown
# Lesson: [short title]

## Observation
What happened — the specific incident that triggered this lesson.

## The Lesson
What to do differently — the behavioral correction.

## Source
- Session transcript: [path or date]
- Conversation with: [who]
- Date observed: YYYY-MM-DD

## Hook
- Has hook: yes/no
- Hook name: [if yes, the hook module name]
- Hook type: pre-action | post-action
- Hook status: new | verified | ineffective | harmful | retired

## Retrieval Triggers
Keywords or situations when this lesson applies:
- [trigger 1]
- [trigger 2]

## Verification
- [ ] Hook fires in original scenario
- [ ] Hook produces intended behavior change
- [ ] No critical workflows broken
- Monitoring period: [duration, e.g., 2 weeks]
- Monitoring started: YYYY-MM-DD
- Last verified: YYYY-MM-DD
```
