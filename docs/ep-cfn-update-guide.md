# Entertainment Partners — AWS CloudFormation Stack Update Guide

## Overview

Some AWS accounts connected to Trend Micro Vision One have outdated CloudFormation stacks. These need updating to maintain feature parity, security coverage, and proper telemetry collection.

## Prerequisites

- AWS Console access with CloudFormation permissions for each target account
- Vision One console access (Cloud Security → Cloud Accounts)

## Steps Per Account

### 1. Identify Accounts Needing Updates

1. Log into [Vision One Console](https://portal.xdr.trendmicro.com)
2. Navigate to **Cloud Security** → **Cloud Accounts** → **AWS**
3. Accounts showing **"Update available"** status need attention

### 2. Update the CloudFormation Stack

For each account with an available update:

1. Click the account name to open its details
2. Click **Update Stack**
3. Vision One generates an updated CloudFormation template URL
4. Click the URL — this opens the AWS CloudFormation console directly

### 3. Apply the Update in AWS

1. In the AWS CloudFormation console, the stack will show as needing an update
2. Click **Update** → select **Use current template** (Vision One pre-fills the new template URL)
3. Click **Next** through the parameter pages (defaults are correct)
4. On the review page, check the **IAM capability acknowledgment** checkbox
5. Click **Submit**
6. Wait for the stack status to change to **UPDATE_COMPLETE** (typically 2-5 minutes)

### 4. Verify in Vision One

1. Return to the Vision One Cloud Accounts page
2. The account status should update to current within a few minutes
3. If it doesn't refresh, try clicking the refresh button or wait up to 15 minutes

## Troubleshooting

| Issue | Resolution |
|-------|-----------|
| Stack update fails with rollback | Check IAM permissions — the executing role needs CloudFormation + IAM permissions |
| "Template validation error" | Ensure you're using the URL generated by V1, not an old template |
| Account still shows "Update available" after successful stack update | Wait 15 minutes, then refresh. If persistent, disconnect and reconnect the account |
| Stack is in DELETE_FAILED or other stuck state | May need manual cleanup in AWS CloudFormation before re-deploying |
